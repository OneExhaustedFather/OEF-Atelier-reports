# OEF Atelier — reports

Public place to report **modded trucks and trailers** that show missing or wrong data in the OEF Atelier truck/trailer configurator.

Atelier reads truck definitions from the mods installed on your own PC (read-only). Some mods can't be read — often paid or protected mods whose archives are locked on purpose — and some use files Atelier doesn't understand yet. The **Report** button in the configurator opens a pre-filled issue here; you sign in with your own GitHub account, check it, and submit.

Reports contain only the mod's name, Workshop ID or file name, the model, what Atelier found missing, and version numbers. Please don't attach save files, mod files or screenshots of private information.

Atelier never unlocks protected mods. For a locked mod we may ask the creator for the published specs instead.
